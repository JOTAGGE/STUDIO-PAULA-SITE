# Studio Paula Lima — site demonstrativo

Direção visual baseada na referência enviada: editorial de beauty, verde oliva, off-white, tipografia oversized, composição fotográfica e navegação minimalista. O conteúdo usa os materiais fornecidos e os dados públicos do Maps; informações comerciais não disponíveis foram deixadas neutras.

## Estrutura
- `index.html` — Home
- `sobre.html` — Sobre
- `servicos.html` — Serviços
- `galeria.html` — Galeria com lightbox
- `contato.html` — Contato + Google Maps
- `styles.css` — sistema visual responsivo
- `script.js` — menu mobile
- `public/images/` — fotos fornecidas

## Publicação
É um site estático e pode ser publicado diretamente em Vercel, Netlify, GitHub Pages ou hospedagem tradicional. Basta servir a pasta como raiz do site.

## Dados a confirmar antes do lançamento
Serviços exatos, preços, Instagram, política de agendamento, horários e demais informações comerciais devem ser validados com a cliente.

## Conceito
A marcação “Conceito demonstrativo · NOMA” no rodapé é discreta e pode ser removida na entrega final.
